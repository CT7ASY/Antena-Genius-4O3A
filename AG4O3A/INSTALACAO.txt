AG 4O3A — Instalação
Desenvolvido por Eduardo Arraia — CT7ASY
Software de distribuição gratuita.

REQUISITOS
Windows 10 ou 11 e Microsoft .NET Framework 4.8.

TRANSFERIR
https://github.com/CT7ASY/Antena-Genius-4O3A/releases/latest

INSTALADOR
1. Feche o AG 4O3A, se estiver aberto.
2. Execute Instalar-AG-4O3A-1.0.5.exe.
3. Siga as instruções. Pasta de instalação: C:\CT7ASY\AG 4O3A.
4. Abra a aplicação pelo atalho do Ambiente de Trabalho ou pelo menu Iniciar.

VERSÃO PORTÁTIL
Extraia todos os ficheiros de AG-4O3A-1.0.5-portatil.zip para uma pasta
e execute AG4O3A.exe. Não execute diretamente dentro do ZIP.

PRIMEIRA LIGAÇÃO
Abra a engrenagem e indique o endereço do Antenna Genius.
Substitua o IP inicial 127.0.0.1 ou o hostname remoto de exemplo pelos seus dados.
Escolha Local ou Remota e guarde as definições.

PREFERÊNCIAS
Guardadas em %LOCALAPPDATA%\CT7ASY\AG4O3A.
A palavra-passe remota é protegida pelo Windows para o utilizador atual.
O desinstalador mantém as preferências.

ATUALIZAÇÕES
Sobre > Verificar atualizações abre a página das Releases no GitHub.
A instalação da atualização é manual.

A aplicação não necessita de PowerShell para funcionar.
