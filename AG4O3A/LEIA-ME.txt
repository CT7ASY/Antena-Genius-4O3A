AG 4O3A 1.0.6
Desenvolvido por Eduardo Arraia - CT7ASY
Software de distribuição gratuita.

Aplicação Windows compilada em C# / .NET Framework 4.8.
Não utiliza PowerShell para executar a aplicação.

INSTALAÇÃO
Feche a versão anterior. Execute Instalar-AG-4O3A-1.0.6.exe.
Abra AG 4O3A pelo atalho do Ambiente de Trabalho ou pelo menu Iniciar.
Na primeira utilização, abra a engrenagem e indique o IP do seu equipamento.
O endereço local inicial é 127.0.0.1; o remoto é apenas um exemplo.
Pasta de instalação: C:\CT7ASY\AG 4O3A.
O instalador solicita permissões de administrador.

DEFINIÇÕES
As preferências são guardadas em %LOCALAPPDATA%\CT7ASY\AG4O3A.
Na primeira utilização, o perfil de ligação é importado da pasta
Ambiente de Trabalho\Antenna-View, se estiver disponível.
O idioma e as posições das janelas são mantidos.
As palavras-passe são protegidas pelo Windows para o utilizador atual.
Apenas uma instância pode estar aberta, incluindo a versão PowerShell anterior.

LIGAÇÃO
Compatível com Antenna Genius v4 de 8 antenas. Ligação local ou remota com autenticação.
Ao selecionar uma antena manualmente, a próxima mudança de banda no FlexRadio
configurado faz regressar a porta ao modo FLEX, quando o rádio estiver acessível.
Ao fechar a aplicação ligada ao AG, cada porta com FlexRadio configurado
passa para AUTO. Se a caixa não confirmar, a aplicação permite cancelar a saída.

Stack e o editor de relés estão preparados para consulta; edição ainda indisponível.
A aplicação verifica novas versões ao iniciar. Se houver uma atualização,
mostra o botão Atualizar. Também pode verificar em Sobre > Verificar atualizações.
O instalador é descarregado e verificado antes de abrir. As definições são mantidas.
O Windows poderá pedir autorização para executar o instalador.
Importação/exportação AG 4O3A inclui antenas, bandas, FlexRadio e opções;
não inclui rede, Stack, relés ou palavras-passe. Importar só preenche os campos:
é necessário Aplicar ou Guardar para enviar alterações ao equipamento.

O desinstalador mantém as preferências e o perfil de ligação.

COMPILAÇÃO
build.ps1 compila os ficheiros C# usando o compilador do .NET Framework.
Para gerar também o instalador, indique -InnoCompiler com o caminho de ISCC.exe.
O PowerShell só é usado como ferramenta de compilação, não pela aplicação instalada.
